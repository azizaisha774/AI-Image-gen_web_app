# Pixelle - AI Image Generator (Flask + MySQL)

1. Run schema.sql in MySQL Workbench.
2. Put your MySQL password in app.py (DB dictionary).
3. pip install -r requirements.txt
4. python app.py  ->  http://127.0.0.1:5000

Images come from the free Pollinations.ai endpoint (no API key). Anonymous use is limited to about one image every 15 seconds.
